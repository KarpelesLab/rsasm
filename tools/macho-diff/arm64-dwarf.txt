# The line table and the frame table, in the shapes tools/dwarf-diff checks
# for an ELF object, written in Darwin's assembly.
#
# A frame on arm64 is described twice: once as a compact unwind word in
# `__LD,__compact_unwind`, which the linker reads first, and in
# `__TEXT,__eh_frame` only where the word says the shape is one it cannot
# describe. The frame cases below walk through the shapes the word has --
# a frame pointer prologue, a frameless stack adjustment, each pair of
# callee-saved registers -- and the ones that fall back to the frame table.
