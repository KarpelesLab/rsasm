# Linker relaxation is on here, as it is in both references: llvm-mc runs with
# `-mattr=+relax` and GNU as needs no asking. So a reference to a symbol is
# relocated even where it is a label in this very section, since the linker
# may shorten what lies between, and `R_RISCV_RELAX` marks each relocation the
# linker is allowed to rewrite. The marks are left out of this comparison
# (`canon.sh --ignore-reloc`, see tools/mc-diff/run.sh): llvm-mc writes them
# beside `R_RISCV_JAL`, `R_RISCV_TLS_GOT_HI20` and `R_RISCV_TLS_GD_HI20` as
# well, where GNU as leaves a jump and a thread-local slot alone, and rsasm
# follows GNU as. Which relocations carry one is checked in tests/riscv.rs
# against `riscv64-elf-as`, and what they do by tools/link-diff, which links
# every RISC-V program a second time with `--relax`.
#
# The field a relocated reference covers is left empty, as llvm-mc leaves it
# and as a reference out of the file leaves it; GNU as fills a branch or a
# jump in with the distance as it stands, which no linker reads.
# `R_RISCV_ALIGN` does not appear below because these sections align nothing
# wider than an instruction; tests/riscv.rs covers it, and the two references
# part company over it in a section with nothing to relax, where GNU as
# writes the marker and llvm-mc pads to the boundary itself.
#
# A difference of two labels in one section is the other thing relaxation
# changes, and the one place the references differ in how much they leave to
# the linker. Both write a difference the linker may have to work out as a
# pair of relocations at the field: `R_RISCV_ADD8` to `ADD64` on the symbol
# added and the matching `SUB` on the one subtracted, and
# `R_RISCV_SET_ULEB128` with `R_RISCV_SUB_ULEB128` in a `.uleb128`, which has
# no fixed width for a linker to add into and so keeps the value this file
# computed. What they fold differs: GNU as defers every difference of labels
# in a code section, and every `.uleb128` of a difference wherever the labels
# are, whether or not anything between them can move and even under `.option
# norelax`, while llvm-mc looks at what lies between the two labels and folds
# the difference where none of it is an instruction a linker may rewrite.
# rsasm follows llvm-mc: a difference GNU as defers and this folds is one the
# linker would have worked out to the same number, which tools/link-diff
# checks by linking the same program from both assemblers' objects with
# `--relax`.
