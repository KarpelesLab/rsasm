# AArch64 (A64) differential corpus.
#
# Immediates are mostly written without the usual `#` sigil, which both
# assemblers accept; the SIMD and SVE corpora (aarch64-*-words.txt) write it.
#
# Two general-purpose forms this corpus cannot hold, because only one
# reference reads them. GNU as reads an explicit zero offset in the 64-byte
# accesses (`ld64b x0, [x1, #0]`), where llvm-mc takes the base register
# alone; rsasm follows GNU as, and `tests/aarch64.rs` has the bytes. The
# other way round, llvm-mc assembles `setf8` with no register at all as
# `setf8 w0`, which GNU as refuses and rsasm refuses with it. A third, below:
# llvm-mc takes the zero register for the size a FEAT_MOPS copy or set counts
# down (`cpyfp [x0]!, [x1]!, xzr!`) and GNU as wants a numbered register
# there; rsasm follows llvm-mc, as it does for every AArch64 encoding, so
# those two lines are here rather than in a corpus both references read.
