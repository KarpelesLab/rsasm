# A32 corpus.

# Immediates are written without the `#` sigil: GAS-dialect lexing in this
# assembler treats `#` as a line comment, so `mov r0, #1` never reaches the
# backend. llvm-mc accepts the bare spelling everywhere except inside a shift
# operand (`lsl #3`), which is why no `op rd, rn, rm, lsl #n` line appears
# below even though the backend encodes it; those cases are covered in
# tests/arm.rs from encodings confirmed separately with llvm-mc.
