# T32 (Thumb) corpus.
#
# As in arm.txt, immediates are written without `#` because GAS-dialect lexing
# treats `#` as a comment. llvm-mc's Thumb parser also rejects the bare
# spelling for a few 32-bit forms where a register is the alternative reading
# (`mov.w r0, 291`), so those appear only in tests/arm.rs.
