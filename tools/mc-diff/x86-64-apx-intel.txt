# extended EVEX one: the new destination register, `{nf}`, the conditional
# compares with their flag mask, the conditionally faulting moves, the paired
# pushes, and the instructions Intel moved into an EVEX map so that an
# extended register could reach them.

# forms GNU as 2.47, llvm-mc 22 and rsasm all agree on. The same file is in
# tools/gas-diff and tools/mc-diff; where the two references disagree the case
# is in neither, which is why `xchg` with an extended register, two-operand
# `cfcmov` and `setcc` with a register wider than a byte are missing. Those
# splits are listed in tools/fuzz/x86.py.
