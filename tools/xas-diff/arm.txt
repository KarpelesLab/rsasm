# A32 corpus for GNU as, which checks what llvm-mc's own corpus cannot:
# the instructions the security, virtualization and divide extensions add,
# the banked registers of `msr` and `mrs`, and the shifted operands, whose
# amount llvm-mc wants a `#` on that this assembler's GAS-dialect lexer eats
# as a comment.
#
# GNU as runs with `-march=armv7ve`; see run.sh.
