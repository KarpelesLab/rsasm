# m68k, GNU syntax, against `m68k-elf-as` (which assumes a 68020).
#
# Registers need the `%` sigil here: without it `d0` is a symbol. Comments
# start with `|`, and `#` is the immediate prefix.
#
# Left out on purpose, because rsasm and GNU as legitimately differ:
#   - GNU as substitutes instructions: `movel #1,%d0` becomes `moveq`,
#     `addw #1,%d0` becomes `addq`, and `cmp`/`and`/`or #imm,%dn` become the
#     `I` forms. rsasm assembles what is written.
#   - `label` as an absolute address, which GNU as turns into a PC-relative
#     reference when the label is in the same section.
