# m68k, Motorola syntax, against `m68k-elf-as --mri` (which assumes a 68020).
#
# Motorola source is column-sensitive: a word in column 0 is a label. Every
# instruction here is indented.
#
# Left out on purpose, because rsasm and GNU as legitimately differ:
#   - GNU as substitutes instructions: `move.l #1,d0` becomes `moveq`,
#     `add.w #1,(a0)` becomes `addq`, and `cmp`/`and`/`or #imm,dn` become the
#     `I` forms. rsasm assembles what is written; see m68k-vasm.txt.
#   - `(a0,d1)` with no index size is a long to GNU as and a word to Motorola,
#     vasm and rsasm.
#   - `(pc)` or `8(pc)` with a constant, which GNU as `--mri` reads as an
#     absolute address to relocate; and `label` as an absolute address, which
#     GNU as turns into a PC-relative reference when it can.
#   - `bhs`/`blo` without a size, which GNU as alone never relaxes.
