# AArch64 snippets compared against GNU as, which is the other reference for
# the families here. FEAT_MOPS and FEAT_CMPBR are in the llvm-mc corpora as
# well; FEAT_TME's transactions are only here, since llvm-mc 22 has no name
# for that extension at all.
#
# A copy or a set warns here about opening a dependency sequence without
# ending the one before it, which is a warning about the program and not
# about any one encoding.
#
# After them come the snippets where `.arch`, `.cpu` and `.arch_extension`
# decide which instructions assemble: the reference runs with the `-march=`
# that names every extension (see run.sh), which each directive overrides, so
# what is left is what the architecture or CPU named really has. Snippets both
# assemblers refuse are in aarch64-relocs.txt, which compares whole objects
# and takes a `refused:` name. See `src/arch/aarch64/cpu.rs`.

	.arch	armv8-a
	.arch_extension memtag

=== an extension dragging in the ones it is defined with

	adclb	z0.s, z1.s, z2.s
	ld1b	{ z0.b }, p0/z, [x0]
=== taking an extension away takes away what depends on it
	.arch	armv9-a
	.arch_extension nosve
	nop
